## 🎯 ¿Qué veremos en este módulo?

*   **Sistemas Numéricos:** Binario, Hexadecimal y Octal.
*   **Complemento a 2:** Cómo funcionan realmente los números negativos.
*   **Tabla ASCII:** La ilusión óptica detrás del texto.
*   **Arquitectura Básica:** Layout de memoria y jerarquías.

## 🏆 Lo que dominarás al terminar
Obtendrás el conocimiento de arquitectura fundamental que todo ingeniero de software necesita para comprender los misterios de bajo nivel de C.
