# Detector de Palíndromos

Un palíndromo es una palabra o frase que se lee igual en sentido directo que inverso cuando se ignoran los espacios y las diferencias entre mayúsculas y minúsculas (por ejemplo, "anita lava la tina" o "reconocer"). Escribe un programa que determine si una cadena de texto ingresada es un palíndromo.

## Entrada
Una única línea de texto.

Límites:
- 1 <= Longitud <= 1000

## Salida
Imprime una única línea con el mensaje:
- `Es palindromo.` si la cadena cumple la propiedad.
- `No es palindromo.` en caso contrario.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| anita lava la tina | Es palindromo. |
| reconocer | Es palindromo. |
| hola mundo | No es palindromo. |
| A Santa at NASA | Es palindromo. |
