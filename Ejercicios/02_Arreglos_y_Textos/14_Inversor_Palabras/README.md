# Inversor de Cadenas de Texto

Invertir el contenido de una cadena de caracteres consiste en reflejar el orden de todos sus símbolos, de modo que el último carácter pase a ser el primero. Escribe un programa que lea una línea de texto e imprima la cadena completamente invertida.

## Entrada
Una única línea de texto.

Límites:
- 1 <= Longitud <= 1000

## Salida
Imprime una única línea con la cadena de texto invertida.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| Hola Mundo | odnuM aloH |
| Estructuras | sarutcurtsE |
| A | A |
