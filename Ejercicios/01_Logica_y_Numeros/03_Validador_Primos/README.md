# Validador de Números Primos

Un número entero mayor que $1$ se considera primo si únicamente es divisible entre $1$ y entre sí mismo. Los números menores o iguales a $1$ no son primos, y los enteros mayores a $1$ que tienen más de dos divisores se denominan compuestos. Escribe un programa que determine si un número entero positivo es primo.

## Entrada
La entrada consiste en una única línea que contiene un número entero $N$.

Límites: 1 <= N <= 10^9

## Salida
Imprime una única línea con el mensaje:
- `N es primo.` si el número es primo.
- `N no es primo.` si el número no es primo.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| 7 | 7 es primo. |
| 4 | 4 no es primo. |
| 1 | 1 no es primo. |
| 2 | 2 es primo. |
| 29 | 29 es primo. |
