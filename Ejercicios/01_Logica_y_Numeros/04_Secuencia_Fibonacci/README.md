# Secuencia de Fibonacci

La sucesión de Fibonacci es una secuencia matemática en la cual cada término se obtiene sumando los dos términos anteriores, iniciando convencionalmente con $0$ y $1$. Los primeros valores de la sucesión son $0, 1, 1, 2, 3, 5, 8, 13, \dots$. Escribe un programa que reciba un número entero positivo $N$ e imprima los primeros $N$ términos de la sucesión en una sola línea, separados por un espacio.

## Entrada
La entrada consiste en una única línea que contiene un número entero positivo $N$.

Límites: 1 <= N <= 50

## Salida
Imprime en una sola línea los primeros $N$ términos de la sucesión de Fibonacci separados por un espacio.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| 5 | 0 1 1 2 3 |
| 1 | 0 |
| 7 | 0 1 1 2 3 5 8 |
| 2 | 0 1 |
