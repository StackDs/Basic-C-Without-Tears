# Inversor de Dígitos

Invertir el orden de las cifras de un número es un problema habitual para practicar las operaciones de residuo (`%`) y cociente (`/`) en aritmética entera sin necesidad de manipular cadenas de texto. Escribe un programa que reciba un número entero y produzca el valor resultante de invertir sus dígitos de forma matemática. Si el número original es negativo, el número resultante debe conservar el signo negativo.

## Entrada
La entrada consiste en una única línea que contiene un número entero $N$.

Límites: -2000000000 <= N <= 2000000000

## Salida
Imprime un único número entero correspondiente a $N$ con sus dígitos en orden inverso.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| 1234 | 4321 |
| -567 | -765 |
| 1200 | 21 |
| 0 | 0 |
