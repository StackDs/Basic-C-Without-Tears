# Suma de los N Primeros Números

Calcular la suma acumulada de los primeros números naturales es uno de los primeros pasos para entender cómo estructurar bucles e iteraciones. Tu objetivo es escribir un programa que lea un número entero positivo $N$ y calcule la suma de todos los números enteros desde $1$ hasta $N$ utilizando una estructura de repetición.

## Entrada
La entrada consiste en una única línea que contiene un número entero positivo $N$.

Límites: 1 <= N <= 10^6

## Salida
Imprime un único número entero que represente la suma de todos los números desde $1$ hasta $N$.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| 5 | 15 |
| 10 | 55 |
| 1 | 1 |
| 100 | 5050 |
