# Suma de Dígitos

La descomposición de un número en sus cifras decimales individuales es una técnica elemental utilizada en algoritmos de validación y propiedades aritméticas. Escribe un programa que lea un número entero $N$ y calcule la suma de todos sus dígitos, considerando cada dígito como positivo sin importar el signo del número original.

## Entrada
La entrada consiste en una única línea que contiene un número entero $N$.

Límites: -2000000000 <= N <= 2000000000

## Salida
Imprime un único número entero que represente la suma de los dígitos individuales de $N$.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| 1234 | 10 |
| -505 | 10 |
| 0 | 0 |
| 999 | 27 |
