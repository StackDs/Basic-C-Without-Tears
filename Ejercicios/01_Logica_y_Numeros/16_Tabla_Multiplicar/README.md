# Tabla de Multiplicar Flexible

Las tablas de multiplicar constituyen una base importante del cálculo aritmético. En lugar de limitarse al rango estándar del 1 al 10, escribe un programa que reciba un número base $M$ y un límite superior $N$, y genere la tabla de multiplicar de $M$ desde $1$ hasta $N$.

## Entrada
La entrada consiste en una única línea que contiene dos números enteros $M$ y $N$ separados por un espacio.

Límites:
- -1000 <= M <= 1000
- 1 <= N <= 100

## Salida
Imprime $N$ líneas con el formato `M x i = resultado`, donde $i$ varía desde $1$ hasta $N$.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| 7 4 | 7 x 1 = 7<br>7 x 2 = 14<br>7 x 3 = 21<br>7 x 4 = 28 |
| 12 2 | 12 x 1 = 12<br>12 x 2 = 24 |
