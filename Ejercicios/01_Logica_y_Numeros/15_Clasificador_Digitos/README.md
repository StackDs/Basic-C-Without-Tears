# Clasificador de Dígitos

Analizar la composición de las cifras de un número permite extraer propiedades estructurales de los datos. Escribe un programa que lea un número entero $N$ y determine cuántos de sus dígitos son pares y cuántos son impares. Ten en cuenta que el dígito `0` se clasifica como par.

## Entrada
La entrada consiste en una única línea que contiene un número entero $N$.

Límites: -2000000000 <= N <= 2000000000

## Salida
Imprime una única línea con el formato `Pares: P, Impares: I`, donde $P$ es la cantidad de dígitos pares e $I$ es la cantidad de dígitos impares.

## Ejemplos
| Entrada | Salida |
| :--- | :--- |
| 2468 | Pares: 4, Impares: 0 |
| 13579 | Pares: 0, Impares: 5 |
| 10203 | Pares: 3, Impares: 2 |
| 0 | Pares: 1, Impares: 0 |
| -1234 | Pares: 2, Impares: 2 |
