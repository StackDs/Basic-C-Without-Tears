## 🎯 ¿Qué veremos en este módulo?

*   **Arreglos 1D:** Agrupando múltiples variables del mismo tipo.
*   **Iteración:** Recorriendo posiciones en memoria mediante índices.
*   **Matrices N-Dimensionales:** Creando cuadrículas y tableros virtuales.
