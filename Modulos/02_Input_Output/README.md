## 🎯 ¿Qué veremos en este módulo?

*   **El poderoso printf:** Formateo de cadenas y variables en la salida estándar.
*   **El peligroso scanf:** Lectura de datos desde el teclado y el uso del ampersand.
*   **Buffers:** El concepto de salto de línea y la limpieza del buffer.

## 🏆 Lo que dominarás al terminar
Serás capaz de interactuar con el usuario mediante la consola de forma segura, formateando salidas y capturando entradas sin crashear el programa.
