# Módulo 14: Operaciones de Bits

El nivel más bajo de programación lo encontrarás aquí (al menos conceptualmente). Aquí no hay variables amigables, solo ceros y unos. Domina el arte del "bit hacking" para máxima eficiencia y control absoluto sobre el hardware, aplicando operaciones a nivel de bits como desplazamiento, el uso de operadores
AND, OR, NOT, etc.

## 🎯 ¿Qué veremos en este módulo?

*   **Operadores Lógicos a Nivel de Bit:** AND, OR, XOR y NOT.
*   **Bit Shifting (<< y >>):** Multiplicaciones súper rápidas.
*   **Bitmasking:** Empaquetando 8 booleanos en 1 solo byte.

## 🏆 Lo que dominarás al terminar
Hablarás el verdadero idioma de la máquina, manipulando banderas booleanas y empaquetando datos a un nivel de optimización extremo.
