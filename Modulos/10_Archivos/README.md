## 🎯 ¿Qué veremos en este módulo?

*   **Punteros a Archivo (`FILE*`):** Abriendo y cerrando flujos de datos.
*   **Modos de Lectura/Escritura:** Texto plano vs binario.
*   **Navegación:** Usando fseek y ftell para moverte por el archivo.
