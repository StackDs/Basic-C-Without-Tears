## 🎯 ¿Qué veremos en este módulo?

*   **Structs:** Agrupando variables de distintos tipos en un solo bloque.
*   **Typedef:** Creando tus propios tipos de datos personalizados.
*   **Enums:** Reemplazando números mágicos con constantes legibles.
