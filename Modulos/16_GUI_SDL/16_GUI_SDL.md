# Módulo 16: Interfaz Gráfica y Videojuegos con SDL3

Bienvenido al módulo donde aplicaremos todo lo aprendido y además incorporaremos una GUI funcional. Vamos a construir un videojuego 2D muy simple, el cual será **un laberinto de escape interactivo** con gráficos en tiempo real, eventos, tipografía, cronómetro y audio con la moderna biblioteca **SDL3**.

Para que el proceso sea progresivo y modular, vamos a dividir esto en 6 submódulos prácticos e incrementales:
